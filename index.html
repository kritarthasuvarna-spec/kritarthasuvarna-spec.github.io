What I do

Idea in, game-ready out

Five stages, one person. Hand me a concept and get back an asset that runs.

  1. Modeling

    Hard surface and organic, stylized and realistic, low poly to budget.

  2. Texturing

    Hand-painted and PBR in Substance 3D Painter.

  3. Rigging

    Character and prop rigs, custom deformers, Spine 2D.

  4. Animation

    Game loops, state machines and blend trees.

  5. Engine integration

    Unity setup, LODs, texture atlasing and optimization.

FootNote

Leave a note on any file, right inside Windows Explorer, so every saved version tells you what it is. No renaming files into paragraphs.

  • Right-click any file or folder and choose "Add FootNote"
  • Reminders, clickable links and Markdown or CSV export
  • Notes never modify the file itself
